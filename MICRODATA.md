# Микроразметка в системе автоматизации

## Что такое микроразметка и почему она важна для SEO

Микроразметка – это специальный формат разметки на сайте, который помогает поисковым системам лучше понять содержание страниц. Вместо того чтобы гадать, что изображено на странице, поисковый робот получает структурированные данные о странице: что является заголовком статьи, где указаны автор и дата, какие элементы являются отзывами, рейтингами, вопросами и ответами и т.д.

Проще говоря, микроразметка – это язык, на котором сайт общается с поисковиком, описывая свою информацию более понятно и точно. Для SEO это имеет большое значение.

### Преимущества микроразметки

1. **Расширенные сниппеты** - правильно добавленная микроразметка делает ваш сайт кандидатом на расширенные результаты
2. **Увеличение CTR** - такие сниппеты заметнее и привлекательнее для пользователей
3. **Лучшее понимание контента** - структурированные данные помогают Google более точно проиндексировать и понять контекст страницы
4. **Улучшение ранжирования** - косвенно влияет на позиции: если поисковик лучше понимает контент, ему проще сопоставить его с релевантными запросами

## JSON-LD – рекомендованный формат

Google поддерживает три основных формата разметки структурированных данных: Microdata, RDFa и JSON-LD. В нашей системе мы используем только JSON-LD, так как это рекомендованный способ от Google, а остальные форматы устарели.

JSON-LD представляет данные в формате JSON, которые вставляются в код страницы внутри тега `<script type="application/ld+json">`. Это рекомендованный Google способ внедрения микроразметки. JSON-LD не требует изменять существующий HTML-код – вы просто вставляете отдельный блок со структурированными данными.

## Автоматическая реализация в системе

### Генерация контента с микроразметкой

Каждый фрагмент контента, создаваемый системой автоматизации, автоматически включает:

1. **Подробное объяснение микроразметки** - пользователи узнают о важности структурированных данных
2. **Практические советы** - рекомендации по использованию различных типов схем
3. **Автоматические JSON-LD схемы** - система генерирует соответствующие структурированные данные

### Поддерживаемые типы схем

#### 1. Article Schema (Статьи и блоги)
Используется для всех статей и постов блога:
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Заголовок статьи",
  "author": {
    "@type": "Person",
    "name": "Автор"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Название сайта"
  },
  "datePublished": "2024-01-01",
  "description": "Описание статьи"
}
```

#### 2. FAQ Schema (Часто задаваемые вопросы)
Автоматически добавляется к каждой странице с информацией о микроразметке:
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Что такое микроразметка?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Подробный ответ о микроразметке"
      }
    }
  ]
}
```

#### 3. VideoGame Schema (Страницы игр)
Для описания игр, слотов и других развлечений:
```json
{
  "@context": "https://schema.org",
  "@type": "VideoGame",
  "name": "Название игры",
  "genre": "Casino Game",
  "author": {
    "@type": "Organization",
    "name": "Разработчик"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": 4.5,
    "bestRating": 5
  }
}
```

#### 4. Review Schema (Обзоры и рейтинги)
Для страниц с обзорами казино, игр и сервисов:
```json
{
  "@context": "https://schema.org",
  "@type": "Review",
  "itemReviewed": {
    "@type": "Thing",
    "name": "Объект обзора"
  },
  "reviewRating": {
    "@type": "Rating",
    "ratingValue": 4.5,
    "bestRating": 5
  },
  "author": {
    "@type": "Person",
    "name": "Автор обзора"
  }
}
```

#### 5. BreadcrumbList (Хлебные крошки)
Для улучшения навигации и отображения в поиске:
```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://example.com/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Статьи",
      "item": "https://example.com/articles/"
    }
  ]
}
```

## Практические рекомендации

### Внедрение через WordPress плагин

Система автоматически:
1. Генерирует соответствующие схемы при сохранении поста
2. Выводит JSON-LD в секции `<head>` страницы
3. Показывает статус схем в админке WordPress
4. Предоставляет ссылку для проверки в Google Rich Results Test

### Использование API

Генерация специализированных схем через API:
```bash
curl -X POST "http://localhost:8000/schema/generate" \
  -H "Content-Type: application/json" \
  -d '{
    "schema_type": "game",
    "title": "Aviator",
    "description": "Популярная краш-игра",
    "rating": 4.7
  }'
```

### Автоматический мониторинг

Система включает:
- **Ежедневную проверку** структурированных данных
- **Еженедельные отчеты** по использованию микроразметки
- **Автоматические рекомендации** для улучшения SEO

## Проверка и валидация

### Инструменты проверки

1. **Google Rich Results Test** - https://search.google.com/test/rich-results
2. **Google Search Console** - отчеты по расширенным результатам
3. **Schema.org Validator** - дополнительная проверка синтаксиса

### Мониторинг эффективности

- Отслеживание появления расширенных сниппетов
- Анализ CTR на страницах с микроразметкой
- Мониторинг ошибок структурированных данных

## Рекомендации по использованию

1. **Соответствие контенту** - данные в схемах должны точно отражать содержание страницы
2. **Избегание дублирования** - не используйте одинаковые схемы на разных типах контента
3. **Регулярная проверка** - мониторьте отчеты в Google Search Console
4. **Постепенное внедрение** - начните с базовых схем (Article, FAQ) и постепенно добавляйте специализированные

# Система автоматизации установки WordPress + Cloudflare + Grafana

Комплексная система автоматизации для развертывания современного веб-стека с мониторингом, CDN и защитой.

## Компоненты системы

### 1. WordPress
- Автоматическая установка последней версии WordPress
- Настройка базы данных MySQL/MariaDB
- Конфигурация PHP и веб-сервера (Nginx/Apache)
- SSL-сертификаты через Let's Encrypt

### 2. Система автоматизации контента
- API для автоматического создания контента
- Интеграция с внешними сервисами
- Автоматическая SEO-оптимизация с микроразметкой
- JSON-LD схемы для всех типов контента
- Автоматическое добавление информации о микроразметке

### 3. Cloudflare
- Автоматическая настройка DNS
- Конфигурация CDN и кеширования
- Настройка правил безопасности
- SSL/TLS оптимизация

### 4. Grafana + Prometheus
- Мониторинг системных ресурсов
- Мониторинг веб-приложений WordPress
- Аналитические дашборды
- Система алертов и уведомлений

## Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd automation-system
   ```

2. Запустите интерактивный установщик:
   ```bash
   sudo ./install.sh
   ```

3. Выберите метод установки:
   - **Полная автоматическая** (рекомендуется для новых пользователей)
   - **Docker Compose** (для контейнеризованного развертывания)
   - **Ansible** (для множественных серверов)
   - **Ручная установка** (для кастомизации)

4. Следуйте инструкциям на экране и настройте `.env` файл

## Требования

- Ubuntu 20.04+ / CentOS 8+ / Debian 11+
- Docker и Docker Compose
- Минимум 4GB RAM и 20GB диска
- Доменное имя для настройки Cloudflare

## Конфигурация

Все настройки находятся в файле `.env.example`. Скопируйте его в `.env` и настройте под ваши нужды.
